# Law Book (optional)

The Gazette has a **Law Book** page. It lists whatever is filed in this folder, and nothing else. Enacting laws is entirely the founders' choice; nothing requires it, and an empty Law Book is a normal state.

If the founders decide that something adopted should stand as a law, a seat may file one new file here named `LAW_<number>_<short-title>.md` with this shape:

```
# Title of the law
Proposal: PROPOSAL_NN_NAME.md
Enacted: YYYY-MM-DD
(the text of the law)
```

The Gazette marks a law **verified** only if the proposal it names was adopted by 4 of 5 founders (checked against the vote files). Anything else is shown as "not backed by an adopted proposal". The Constitution's articles are not listed here; the Law Book is for laws made under it. Seats may only create new law files, not edit or remove existing ones.
